# Taiwan Stock v28（台股分析）

沿用既有 Jerry 台股 V28 框架：公司行動校正 + 證據分層 + 反證 + 失效條件。

## 觸發
使用者要分析台股個股（2330 / 3706.TW / 華邦電 等）。

## 工作流程
1. 數值資料優先由 backend 取得：`get_analysis_packet(market="taiwan", target="<代碼>", horizon="1d", detail_level="normal")`。
2. 需個別資料才呼叫 `analyze_taiwan_stock(stock=..., horizon=...)`。
3. 避免 LLM 自己重複抓資料。

## 分析結構（證據分層）
1. **公司行動校正**：除權除息、增減資、分割，校正價格才可比。
2. **證據分層**：價量 → 籌碼 → 基本面 → 事件。
3. **反證**：主動找相反的證據，不要只找支持結論的資料。
4. **失效條件**：明確寫出「什麼情況下這個看法作廢」。

## 輸出
- 偏多／偏空／盤整 + 主要區間 + 支撐／壓力 + 失效條件 + 重新分析時機。
- 不得製造假 probability。
