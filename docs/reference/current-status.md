# Current Status

Describes the current `main` branch. This is separate from the immutable
[`v2.0.0-rc1` release snapshot](../../research/releases/v2.0.0-rc1/).

Runtime values (build id, git commit, test count) are generated by runtime introspection — run
`get_system_info` via MCP, or:

```powershell
python -c "from market_ai_hub.services.build_info import build_fingerprint; print(build_fingerprint())"
```
