## 重要：不是所有資料都全自動

- **PUBLIC/API providers**（證交所、期交所、Cboe…）：系統可以按需求自動抓。
- **225LABO**：這是日經 Micro 的關鍵分鐘資料，**目前合法的做法是「手動下載」**，下載後系統會自動匯入。
- **Yuanta**：選用，目前**沒有交易下單**。

## 225LABO 更新流程（最白話）

```
你去 225LABO 官方下載新檔
        ↓
把檔案放進 private inbox 資料夾
        ↓
執行 import_latest_225labo_micro.ps1
（或直接跑 daily cycle）
        ↓
系統自動：hash → 驗證 → 去重 → 增量匯入
        ↓
資料變成「FRESH（新鮮）」
```

- **原始檔案不會進 GitHub**（那是你的私人授權資料）。
- 檔案放進的資料夾（example）：`D:\MARKET_AI_HUB_PRIVATE_INBOX\225labo`

## 如果不更新 225LABO 會怎樣？

Forward Shadow 會因為資料過期而**自動跳過**（顯示「資料過期」），不會硬跑出錯誤預測。

這不是壞事——**「誠實跳過」比「硬產生一個不可信的預測」更好**。
