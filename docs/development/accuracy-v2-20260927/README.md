# Accuracy v2 文件包使用方式

這是2026-09-27第二版「精度提升」規劃，取代上一包的設計與兩份prompt。既有程式修復保留；新模型／新特徵尚未施工，沒有宣称準確率已提高。

1. `PROJECT_INSTRUCTIONS.txt`：全文替換ChatGPT專案設定「指示」欄；不是PowerShell安裝命令。
2. `ACCURACY_V2_PROJECT_SOURCE.md`：上傳專案來源。它自含現況、取捨、模型設計、驗收、路線圖與免費原始來源，可單獨使用。
3. `START_NEXT_CHAT.txt`：貼在該專案的新聊天，開始P0/P1實作。WebCodex主施工，Remote Desktop Commander備援。
4. 舊vNext來源與舊PDF移除或標「歷史參考」；若保留上一包01修復報告與05驗收，明確標為修復歷史，不覆蓋本次設計。

本包是方法研究／施工契約更新；既有1995測試通過不等於候選模型已驗證。本次沒有訓練模型或修改live設定。模型是否更準，要在新未曝光資料與預登記protocol中比較。
