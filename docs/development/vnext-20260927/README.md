# 使用方式

1. 開啟 `PROJECT_INSTRUCTIONS.txt`，全文複製到 ChatGPT 專案設定的「指示」欄。這不是安裝shell命令，不要貼到PowerShell。
2. 把 `01_CURRENT_STATE_AND_REPAIRS.md`、`02_ARCHITECTURE_AND_ROADMAP.md`、`03_FREE_SOURCES_AND_TOOL_WORKFLOW.md`、`05_DELIVERY_EVIDENCE.md` 上傳為專案資料來源。可用隨包提供的合併版 `UPLOAD_ALL_CONTEXT.md`，二擇一，不必重複上傳。
3. 新開該專案聊天，全文貼上 `START_NEXT_CHAT.txt`，啟用 WebCodex；Remote Desktop Commander 只作備援。
4. 舊 PDF 若保留，標記為「歷史草案，以2026-09-27修訂版為準」。新工作包完成後替換目前狀態與驗收快照，不堆疊互相衝突的 current 文件。

本包未自動修改網頁專案設定或上傳Sources；需要使用者貼上／上傳。repo 中這份文件不含private market data、帳密或原PDF內容全文。
