# 電腦資源保護（新手版）

> 這套系統會不會把電腦吃到卡死？不會，因為有「資源守門員」。

---

## 預設：DESKTOP_SAFE（桌面安全模式）

系統**預設**用最保守的模式，確保你的電腦（瀏覽器、Cherry Studio、其他程式）隨時順暢。

| 資源 | 限制 |
|------|------|
| GPU 顯示卡記憶體 | 最多用 65%（保留約 4GB 給其他程式） |
| CPU | 保留 25% 的執行緒給系統 |
| RAM 記憶體 | 最多用 65% |
| 程式優先權 | BelowNormal（低優先，不搶前台） |
| Optuna 搜尋 | 一次只跑 1 個（不並行） |

## Heavy GPU job 最多一個

大型模型（TimesFM、Chronos、NHITS、NBEATSx）的訓練/微調，**同時間最多一個**。不會好幾個模型一起搶 GPU。

## 如果電腦正在忙？

訓練會**延後（defer）**，不會硬搶。狀態會顯示「資源忙碌，已延後」。

## 其他兩個模式（要你主動選才會用）

| 模式 | 說明 | 預設? |
|------|------|-------|
| DESKTOP_SAFE | 桌面優先（最保守） | ✅ 預設 |
| BALANCED | 平衡（較重研究） | ❌ 要手動切 |
| TRAINING_MAX | 最大訓練吞吐（會吃較多資源） | ❌ 要手動切，不建議日常用 |

**不要為了跑快，把 TRAINING_MAX 當日常預設。**

## 萬一資源監控壞了？

如果系統讀不到 GPU/RAM 的資訊，**重型訓練會直接不啟動**（fail closed），而不是硬跑。

這叫「寧可不做，不要做錯」。

## 緊急停止

如果真的卡住，可以用「安全停止」：讓目前的訓練存好進度（checkpoint）後退出，而不是直接強制關閉。
